# Котик

Личное веб-приложение-сюрприз. Статический фронтенд: React, TypeScript, Vite. Без сервера, без аккаунтов и без внешних API.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`). Флаг `--host` уже включён, поэтому ту же страницу можно открыть с iPhone в той же сети.

Сборка:

```bash
npm run build
npm run preview
```

Для GitHub Pages репозитория `kotik`:

```bash
npm run build:gh
```

Либо задайте путь вручную:

```bash
npx vite build --base /kotik/
```

На GitHub: Settings → Pages → Deploy from a branch, ветка `main`, папка `/docs` **или** GitHub Actions, которая публикует `dist`. После сборки с `--base /kotik/` файлы из `dist` должны лежать в корне Pages-сайта этого репозитория.

В `public/` лежит `.nojekyll`, чтобы GitHub Pages не игнорировал файлы, начинающиеся с `_`. Картинки кладите в `public/images/` и указывайте путь вида `images/caprese.jpg` в конфиге — `base` подставится сам.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Часовой пояс и дата открытия главного экрана | `src/config/app.ts` |
| Тексты главного экрана, меню, заглушки | `src/config/app.ts` |
| Четыре блюда, фото, ингредиенты, шаги, время открытия | `src/config/dishes.ts` |
| Расписание «действия сейчас» | `src/config/actions.ts` |
| Заготовка раздела «Буси» (пока выключен) | `src/config/busi.ts` |

Времена пишите как локальные для `Europe/Warsaw`, формат `YYYY-MM-DDTHH:mm:ss`. Пример уже стоит в `mainUnlockAt`: `2026-10-25T00:00:00`. Не используйте часовой пояс браузера посетительницы — проверка всегда идёт по Варшаве, с учётом летнего/зимнего времени.

Пока у блюда `unlockAt: null`, карточка закрыта. Пока у действий `startsAt: null`, на экране «Действия сейчас» показывается «Расписание будет добавлено позже», а не выдуманное текущее действие.

Пока массивы `ingredients` и `steps` пустые, открытое блюдо показывает «Рецепт будет добавлен позже». Когда появятся шаги, экран сам включит отметки ингредиентов и переход «Дальше». Отметки сохраняются на устройстве в `localStorage` (`kotik.checklist.v1`).

## Preview

Preview **не включён** в обычной сборке и в production. Он работает только в `npm run dev` и только с явным параметром:

```
http://localhost:5173/?preview=1
```

Полезные параметры (настоящий конфиг при этом не меняется):

- `at=2026-10-24T23:59:50` — подставить «сейчас» как варшавское время
- `main=open` / `main=closed` — открыть или закрыть переход в меню
- `dishes=all` / `dishes=none` — все карточки открыты или закрыты
- `schedule=demo` — показать одну явно помеченную демо-карточку расписания

На экране появится тёмная панель «Режим preview». Это не защита: ссылку с `?preview=1` можно переслать, поэтому в production флаг игнорируется.

## Важно про «секреты»

Это статический сайт. Даты открытия видны в клиентском коде. Они нужны для сюрприза, а не как настоящий замок.
